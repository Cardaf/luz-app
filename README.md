# הלוז שלי

לוז אישי לתורים וסידורים. משתפים הודעה מוואטסאפ או צילום מסך, והפרטים (מה, מתי, איפה, טלפון, חשיבות) מתמלאים לבד.

## התקנה
1. Settings ← Pages ← Source: Deploy from a branch ← `main` ← `/(root)` ← Save.
2. בטלפון: לפתוח את כתובת ה-Pages בכרום ← תפריט ⋮ ← "התקנת אפליקציה".
3. באפליקציה: הגדרות ← להדביק מפתח מ-console.anthropic.com (API Keys) ← שמור ובדוק.

## פרטיות
התורים והמפתח נשמרים רק בטלפון (localStorage). הודעות וצילומים נשלחים ישירות ל-Anthropic רק כשלוחצים "מלא לבד". אין שרת.

## עדכון
מעלים את הקבצים החדשים מעל הישנים. האפליקציה מתעדכנת בפתיחה השנייה אחרי ההעלאה.
